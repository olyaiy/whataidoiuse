# whataidoiuse.com

One line per task. Which AI model to use, right now.

> For coding: ...
> For writing: ...
> For research: ...

A plain-language answer to "which AI do I use for this?", updated as models change. Each pick is backed by public benchmarks plus hands-on testing, with a one-line reason and a last-changed date. Click a category to see the numbers behind the pick.

## Status

Day one. Domain registered 2026-11-05. Nothing built yet.

## Plan

- One page, one list: task → pick → why → updated
- Each category maps to a small set of benchmark signals, with manual overrides where hands-on testing disagrees
- Data pulls automatically; verdicts stay human
